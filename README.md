课程文字自动保存到本机 SQLite，名称为 `日期-序号`（如 `2026-11-07-001`，每天重新编号）。原文、译文和未定稿内容持续保存，关闭页面后可在“历史课程”查看并导出 TXT。暂停、继续和断线重连保留同一课程名称，不保存音频。首次更新此功能后请重新构建前端并重启后台。


## 默认设置与方言后端

前端统一使用豆包标准同传、标准近讲收音和 80ms 音频包，不再显示这三项选择控件。音频输入、翻译方向和字幕显示设置仍可调整。

后端保留实验性的腾讯云方言链路，当前前端不提供入口。该链路自动处理普通话及模型支持的方言/口音，无需逐一指定地区；使用腾讯云 ASR 转写和 TokenHub 按句翻译，需单独开通服务并配置凭证。河南、湖北在模型支持范围内，鄂西北具体口音效果与课堂时延仍待实测。

配置方式、费用/数据去向与验证边界见 [用户指南](user_readme.md#可选方言模式实验性需单独开通服务)。程序不会自动修改现有 `.env`。


## 人智学课程术语表（豆包同传）

默认豆包同传现在在启动课程时读取 [`terminology/anthroposophy.json`](terminology/anthroposophy.json)，将专业热词和中英术语表随同一个 `StartSession` 请求发送。无需另开服务、训练模型或增加逐句翻译请求；音频采集、分包和字幕处理不变。本词表只用于豆包同传，现有可选腾讯方言模式不使用它。

词表三个字段分别为：

- `hot_words`：识别热词数组，优先收录人智学、音语舞、星智学等专业词。
- `zh_en`：中文原词到首选英文译法的映射。
- `en_zh`：英文原词（包含别名）到首选中文译法的映射。

中文→英文只传 `zh_en`，英文→中文只传 `en_zh`，自动中英互译合并两者。热词与合并后的术语源词合计最多 1000 条。同一源词不能指定冲突译法；JSON 不允许重复键、空白词条或额外字段，文件上限 256 KiB。校验失败会显示“课程词表无法读取或格式无效”，不会静默忽略词表后开始翻译。

已按课程要求固定 Eurythmy → 音语舞、Astrosophy → 星智学、Astrology → 世俗占星、I-Organization → 自我体。区分黄道（Ecliptic）与黄道带（Zodiac）、律动（Movement）与音语舞（Eurythmy）；Form drawing 回译为形线画，Community 回译为社群。中文近义词、英文别名已分别整理；未填写英文的“现象学观察法”和存在歧义的“塑形艺术”暂未加入。

后续直接编辑该 JSON 文件即可扩充。每次点击开始课程或暂停后继续时重新读取；运行中的自动重连沿用本次启动的词表快照，不在逐句更新或音频发送时读文件。已有正在运行的课程不受文件编辑影响。要停用干预，将文件内容改为 `{"hot_words": [], "zh_en": {}, "en_zh": {}}`，下一次开始/继续生效。

首次安装这次后端改动后，先结束课程、重启 Python 后端，再开始课程。此功能是模型提示，并非模型训练或强制替换；官方明确不保证每次干预生效，实际准确率仍需用课程录音对照验证。接口说明见 [豆包同声传译官方文档](https://docs.volcengine.com/docs/doubao-voice/simultaneous-interpretation2-0-api-access-documentation?lang=zh)。本次自动测试使用模拟云端，不产生付费调用，也不代表已验证真实术语命中率。
